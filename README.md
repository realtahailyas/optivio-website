# optiviomedia.online (legacy site)

> **Archived — superseded by [optivio-automation-site](https://github.com/realtahailyas/OptivioAutomation).** This repository is kept for reference only and is no longer maintained.

Static marketing site for Optivio Media, a Meta Ads agency for Shopify and e-commerce brands. Served from GitHub Pages on the custom domain `optiviomedia.online` (see `CNAME`).

## Contents

- `index.html`: agency landing page
- SEO landing pages and articles on Meta Ads for Shopify (UAE/Dubai, Australia, Canada), budgeting, creative testing, Pixel/CAPI setup, account audits and lead generation
- `case-study-uae-fashion-meta-ads.html`: case study
- `about-taha-ilyas.html`, `thankyou.html`
- `sitemap.xml`, `robots.txt`, images and logos

## Tech

Hand-written HTML and CSS, no build step. To preview locally:

```bash
python -m http.server 8000
```
